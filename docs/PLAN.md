# Bridge 路线图

## 目标
让在同一个项目里工作的多个 AI（目前是 Claude app 和 Codex app）能够：
1. 看到彼此在做什么（状态）
2. 互相留言、交接（消息）
3. 避免同时改同一个文件（认领）

同一套 Bridge 服务所有项目，数据按项目根目录隔离。

## 现状（v0.1 原型）
`bridge.py` 单文件，约 300 行，已经能用：7 个 MCP 工具，SQLite 存储，零依赖。
问题：结构都塞在一个文件里、没有测试、没有版本管理，人只能通过命令行只读地查看。
